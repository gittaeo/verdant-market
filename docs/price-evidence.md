# 가격 그래프와 예측의 구분

2026-10-31: 직선의 보수·기준·낙관 경로 및 예상 수익성 숫자를 제거했습니다. 짧은 종가 평균을 연장하고 고정/대칭 폭을 더한 값은 예측 성능을 검증하지 않았으며 종목별 실제 위험을 제대로 설명하지 못했습니다.

## 현재 제공하는 것

- 실제 최대 5거래일의 종가 연결선, 고저 범위, 거래량. 미래 굴곡·무작위 경로 생성 없음.
- 관측 구간 등락, 종가 기준 최대 낙폭, 일간 단순 수익률의 표본 표준편차(%p, 비연율), 마지막 거래량/이전 관측일 평균.
- 원자료 표 및 계산 기준. 고저·거래량 누락은 자료 없음으로 유지.
- 단타와 장기 후보의 선정 규칙은 유지하되 두 전략 모두 예측 수익률은 산출 보류.
- 저장된 구버전 리포트도 기존 예측 숫자 대신 원자료로 새 그래프 표시.
- 서버 응답 scenarios는 호환용 이름을 유지하되 status=withheld, returns=null, paths={} 및 관측 evidence만 반환. 양수 실적만으로 목표가를 만들지 않음.

## 예측 기능의 완료 기준 — 아직 미구현

1. **자료 확대**: 단기 최소 2년 이상의 수정 일별 OHLCV와 기업행동 이력, 장기 여러 경기 구간의 가격 및 당시 공개됐던 분기 재무자료 확보. 보유 KRX API는 비수정 일별 자료이므로 수정주가를 확보한 것으로 간주하지 않음.
2. **자료 시점 일치**: 거래일별 시장·업종, 외국인·기관 수급, 뉴스 최초 공개 시각과 정정 이력 결합. 상장폐지·거래정지·종목 편입 이력을 포함해 현재 생존 종목만 평가하는 편향 방지.
3. **단기 목표**: 1일/5일 수익률과 손실 폭. 종목별 추세·변동성·거래량·수급·시장 상태를 사용하되 미래 가격을 설명변수로 넣지 않음.
4. **장기 목표**: 3/6/12개월 성과. 실적 변화·밸류에이션·업종 상태와 가격 자료를 사용. 성장률을 임의의 주가 수익률로 환산하지 않음.
5. **시간순 검증**: 학습 구간 이후 검증 구간만 평가, 목표 기간 중첩 차단, 최종 테스트 구간 고정. 현금·시장·단순 추세 기준과 비교. 수수료·세금·슬리피지·거래 가능성 포함.
6. **공개할 성적**: 검증 시점·표본 수·구간별 오차, 방향 적중률, 예측 구간의 실제 포함률, 비용 차감 성과·최대 낙폭. 확률은 보정 성적이 있을 때만 표시. 단순 기준을 이기지 못하면 서비스에서 예상 수익률을 계속 보류.
7. **화면**: 실제 과거 구간과 미래 예측 구간을 분리. 검증된 구간 추정과 오차 표시, 모델 버전·최근 검증 기간·자료 누락 공개. 특정 일자의 지그재그는 미래 경로로 꾸며내지 않음.

사용자 목표인 ‘단타 4개·장기 4개의 예측 수익성 비교’는 이 기준을 통과하기 전까지 미완료입니다. 현재 변경은 잘못된 확신을 주던 표시를 바로잡고 실제 관측 위험을 제공하는 단계입니다.

## 검증

자동 테스트 36개 통과: 구간 수익률·최대 낙폭·누락값·중복 날짜·평탄한 시계열·다른 종목의 차트 차이·기존 API 연결 및 선별 규칙 포함. PC에서 삼성전자 실제 조회 후 5개 종가 및 고저·거래량 그래프 확인. PC 통합 조회와 클라우드 DART 연결 문제는 별개입니다.
